Fedora
boot recovery.

An incomplete update can leave Fedora without files it needs to start. This tool identifies missing boot images and regenerates them automatically.

ShellFedoraMIT License
Explore the source code ↗ for Fedora boot recovery (opens in a new tab)
The story behind the tool ＋

The problem

A partial Fedora update can leave boot images missing, preventing the system from starting correctly.

The approach

The script checks for missing initramfs images and regenerates them with dracut. The repository includes instructions in English, Spanish, and German.

The scope

The project documentation reports testing on Fedora 42. The tool addresses missing boot images; other boot failures may require a different approach.

## Website experience

The content is available in **English and Spanish**, with a flag-based language selector. The site includes **light and dark themes**, a decorative glow setting, SVG icons, and a responsive layout for phones, tablets, and computers.

Preferences are remembered in the browser when storage is available. Navigation supports keyboard use, and the contact form works through standard HTML submission.

## Technologies

**HTML · CSS · JavaScript · SVG · GitHub Pages**

The site is static, with no framework, external JavaScript dependencies, or build process. GitHub Pages publishes the files from the repository root.

## Development and maintenance

To preview it locally, serve the repository folder:

```sh
python -m http.server 8000
```

Open [localhost:8000](http://localhost:8000/) and check both languages, themes, and different screen sizes.

The [maintenance guide](docs/MAINTENANCE.md) covers the file structure, translation editing, and publishing instructions. Keep the README and all repository documentation in English.

## Security and privacy

The page limits the resources it can load through a Content Security Policy. Translations support only text and the formatting required for headings; they do not interpret arbitrary tags or attributes.

Formspree processes the contact form, with spam protection managed through that service. Local preferences store only language, theme, and glow settings. The website code contains no private credentials.
